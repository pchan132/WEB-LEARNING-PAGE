1. JavaScript คืออะไร?

JavaScript (JS) คือ ภาษาโปรแกรมที่ทำให้เว็บไซต์ "มีชีวิต" ได้ — เพิ่มการโต้ตอบ, ตรวจสอบฟอร์ม, โหลดข้อมูลแบบ Real-time และอีกมากมาย

💡
เว็บทุกเว็บที่คุณใช้งาน — Facebook, YouTube, Google — ล้วนใช้ JavaScript ทั้งสิ้น

JavaScript อยู่ตรงไหนใน Fullstack?

// Stack ของ Web Development
HTML  → โครงสร้าง (กระดูก)
CSS   → รูปแบบ (หน้าตา)
JS    → พฤติกรรม (ชีวิตจิตใจ)

// ตัวอย่าง Real-world ที่เจอทุกวัน
- กดปุ่ม "Like" → JS อัปเดต counter
- กรอก Form → JS ตรวจสอบ Email
- เลื่อนหน้า → JS โหลดข้อมูลเพิ่ม (Infinite Scroll)
- ค้นหาสินค้า → JS กรอง + แสดงผลทันที

2. Variables — ตัวแปร

ตัวแปรคือ "กล่อง" สำหรับเก็บข้อมูล ใน JavaScript มี 3 แบบ:

let age = 25;          // เปลี่ยนค่าได้
age = 26;              // ✅ OK — อัปเดตได้

let userName = "สมชาย";  // เก็บชื่อ
let isLoggedIn = false; // สถานะ login
const API_URL = "https://api.example.com";
// ❌ API_URL = "other" → Error! เปลี่ยนไม่ได้

const TAX_RATE = 0.07;  // VAT 7% — ค่าคงที่
const MAX_RETRY = 3;     // จำนวนครั้ง retry สูงสุด

// ✅ ใช้ const ก่อนเสมอ ถ้าจะเปลี่ยนค่าค่อยใช้ let
var oldStyle = "หลีกเลี่ยงการใช้";
// var มีปัญหาเรื่อง Scope และ Hoisting
// นักพัฒนาสมัยใหม่ไม่ใช้ var แล้ว
// ✅ ใช้ let หรือ const แทนเสมอ

4. Operators — ตัวดำเนินการ

// Arithmetic (คณิตศาสตร์)
10 + 3   // 13  บวก
10 - 3   // 7   ลบ
10 * 3   // 30  คูณ
10 / 3   // 3.33 หาร
10 % 3   // 1   เศษ (modulo)
2 ** 10  // 1024 ยกกำลัง

// Comparison (เปรียบเทียบ)
5 === 5   // true  เท่ากัน (แนะนำ)
5 !== 6   // true  ไม่เท่ากัน
5 > 3    // true  มากกว่า
5 >= 5   // true  มากกว่าหรือเท่ากับ

// Logical (ตรรกะ)
true && true   // true  AND
true || false  // true  OR
!true          // false NOT

🧮 เครื่องคิดเลข JavaScript

ผลลัพธ์จะแสดงที่นี่...
✅

5. Control Flow — if / else

ใช้ if/else เพื่อให้โปรแกรมตัดสินใจ — เหมือนเราวางเงื่อนไขในชีวิตจริง

const score = 75;

if (score >= 80) {
  console.log("ผ่านระดับ A");
} else if (score >= 70) {
  console.log("ผ่านระดับ B");  // ← จะทำงานตรงนี้
} else if (score >= 60) {
  console.log("ผ่านระดับ C");
} else {
  console.log("ไม่ผ่าน");
}
🌍
Real-world: ระบบ Login ตรวจสอบว่า password ถูกไหม, ตะกร้าสินค้าตรวจสอบ Stock ก่อน checkout

6. Loops — การวนซ้ำ

ใช้ Loop เพื่อทำซ้ำงาน — ไม่ต้องเขียน Code ซ้ำ ๆ

// for loop — วนจำนวนครั้งที่รู้
for (let i = 1; i <= 5; i++) {
  console.log("รายการที่", i);
}

// while loop — วนจนกว่าเงื่อนไขเป็นเท็จ
let count = 0;
while (count < 3) {
  console.log("retry #" + count);
  count++;
}

// for...of — วนผ่าน Array
const items = ["สินค้า A", "สินค้า B", "สินค้า C"];
for (const item of items) {
  console.log(item);
}

7. Functions — ฟังก์ชัน

Function คือ "สูตรอาหาร" — เขียนครั้งเดียว เรียกใช้ได้บ่อย ๆ

// Function Declaration
function greet(name) {
  return `สวัสดีครับ คุณ ${name}!`;
}

// Arrow Function (ES6) — นิยมมากใน React/Node
const add = (a, b) => a + b;

// Real-world: คำนวณราคาหลังลด VAT
const calcVAT = (price, vatRate = 0.07) => {
  const vat = price * vatRate;
  return {
    original: price,
    vat: vat.toFixed(2),
    total: (price + vat).toFixed(2)
  };
};

💰 ทดลอง Function คำนวณ VAT

ผลลัพธ์จะแสดงที่นี่...
✅
Arrow Function => เป็นแบบที่ใช้บ่อยมากใน Modern JS, React Hooks, Node.js — ฝึกให้คุ้นเคยไว้เลย

8. Arrays — อาร์เรย์

Array คือ "รายการ" — เก็บข้อมูลหลายชิ้นในตัวแปรเดียว เรียงตามลำดับ

const cart = ["เสื้อ", "กางเกง", "รองเท้า"];

// เข้าถึงด้วย index (เริ่มที่ 0)
cart[0]   // "เสื้อ"
cart[2]   // "รองเท้า"

// Methods ที่ใช้บ่อย
cart.push("หมวก");     // เพิ่มท้าย
cart.pop();            // ลบตัวท้าย
cart.length;          // จำนวน = 4

// Modern Array Methods
const prices = [100, 200, 50, 300];
const total = prices.reduce((sum, p) => sum + p, 0);  // 650
const cheap = prices.filter(p => p < 200);            // [100, 50]
const doubled = prices.map(p => p * 2);               // [200,400,100,600]

9. Objects — ออบเจ็กต์

Object เก็บข้อมูลแบบ Key–Value — เหมือน "โปรไฟล์" ที่รวมข้อมูลทุกอย่างของสิ่งหนึ่ง

// สร้าง Object
const user = {
  id: 1,
  name: "สมชาย",
  email: "somchai@example.com",
  isAdmin: false,
  cart: ["เสื้อ", "กางเกง"],       // Array ใน Object ได้!
  greet() {                          // Method ใน Object
    return `สวัสดีครับ ${this.name}`;
  }
};

// เข้าถึงข้อมูล
user.name        // "สมชาย"
user["email"]    // "somchai@example.com"

// Destructuring — ดึงค่ามาเป็นตัวแปร
const { name, email } = user;

// Spread — คัดลอก Object
const updatedUser = { ...user, isAdmin: true };

10. DOM Basics — ควบคุมหน้าเว็บ

DOM (Document Object Model) คือ API ที่ให้ JavaScript ควบคุม HTML ได้ — เปลี่ยนข้อความ, สี, ซ่อน/แสดง Element

// เลือก Element
const btn = document.getElementById("myBtn");
const title = document.querySelector(".title");

// เปลี่ยนข้อความ
title.textContent = "ข้อความใหม่!";

// เปลี่ยนสไตล์
btn.style.backgroundColor = "#f7df1e";
btn.style.color = "black";

// Event Listener — รอรับ Event
btn.addEventListener("click", () => {
  alert("ถูกกดแล้ว!");
});

// Real-world: toggle dark/light mode
document.body.classList.toggle("dark-mode");
