Viewport & Device Simulator

ทดลองจำลองหน้าเว็บบนอุปกรณ์ต่าง ๆ แบบ Real-time

🔑 Meta Viewport Tag — บรรทัดสำคัญที่สุด

โดยปกติมือถือจะแสดงผลเว็บราวกับหน้าจอกว้าง 980px แล้วย่อขนาดลง
tag นี้บอกให้มือถือใช้ความกว้างจริงของตัวเอง

HTML <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- width=device-width → ใช้ความกว้างจริงของหน้าจอ --> <!-- initial-scale=1.0 → ไม่ zoom in/out ตอนโหลดครั้งแรก -->
💡 Real-world tip: ลืม meta viewport tag = มือถือจะแสดงผลเว็บแบบ Desktop ย่อส่วน ลูกค้าโกรธแน่นอน!

บทที่ 3

Media Queries

เงื่อนไข CSS ที่ทำให้ Style เปลี่ยนตามขนาดหน้าจอ

📝 Syntax พื้นฐาน

CSS /* Mobile First (แนะนำ!) */ /* เขียน style สำหรับมือถือก่อน แล้วค่อย override สำหรับจอใหญ่ */ .container { width: 100%; /* mobile */ padding: 0 1rem; } @media (min-width: 768px) { .container { max-width: 720px; /* tablet */ margin: 0 auto; } } @media (min-width: 1024px) { .container { max-width: 960px; /* desktop */ } }

🔄 Mobile First vs Desktop First

📱 Mobile First (min-width) แนะนำ

เขียน base style สำหรับมือถือ → ค่อย add feature สำหรับจอใหญ่ด้วย min-width

🖥 Desktop First (max-width)

เขียน base style สำหรับ Desktop → override สำหรับจอเล็กด้วย max-width

💡 Tip: Google แนะนำ Mobile First เพราะ Performance ดีกว่าบนมือถือ

บทที่ 5

Responsive Units

เลือก Unit ให้ถูกต้องทำให้เว็บ Responsive ได้โดยแทบไม่ต้องเขียน Media Query

📐 เปรียบเทียบ Units แบบ Interactive

ลาก Slider เพื่อเปลี่ยน "font-size ของ html" (base size) แล้วดูว่าแต่ละ Unit เปลี่ยนอย่างไร

🔀 clamp() — The Magic Function

clamp(min, preferred, max) ทำให้ Font หรือ Width ปรับตัวได้อัตโนมัติโดยไม่เกินขอบเขต

CSS /* font-size จะอยู่ระหว่าง 1rem ถึง 3rem */ /* และปรับตาม viewport width */ h1 { font-size: clamp(1rem, 4vw, 3rem); } /* width จะไม่ต่ำกว่า 280px และไม่เกิน 900px */ .container { width: clamp(280px, 90%, 900px); }

📋 Unit Reference

%

Percentage (%)

สัมพันธ์กับ parent element เหมาะกับ width, padding, margin

em

em

สัมพันธ์กับ font-size ของ parent เหมาะกับ padding รอบ text

rem

rem

สัมพันธ์กับ html font-size เหมาะกับ font-size, spacing ทั่วไป

vw/vh

vw / vh

สัมพันธ์กับ viewport width/height เหมาะกับ hero section, full-screen

🏁

Checkpoint 5 — Responsive Units

  • เข้าใจความต่างระหว่าง px, em, rem, %, vw/vh
  • รู้จัก clamp() และเมื่อใดควรใช้
  • เลือก unit ได้เหมาะสมกับแต่ละ property

🧱 แนวคิดพื้นฐาน

  • RWD = เว็บปรับตัวอัตโนมัติ
  • 3 เสาหลัก: Grid, Images, Media Queries
  • Meta Viewport บังคับใส่ทุกโปรเจกต์

📡 Media Queries

  • Mobile First = min-width (แนะนำ)
  • Desktop First = max-width
  • Breakpoints: 480 / 768 / 1024 / 1280

⚡ Layout

  • Flexbox → 1 มิติ (row หรือ column)
  • CSS Grid → 2 มิติ (rows + columns)
  • auto-fit minmax() → Responsive Grid อัตโนมัติ

📐 Units

  • rem สำหรับ font-size, spacing
  • % สำหรับ width ของ container
  • clamp() สำหรับ fluid typography
  • vw/vh สำหรับ full-screen sections
