🟢 Node.js คืออะไร?

Node.js คือ JavaScript Runtime ที่ทำให้เราสามารถรัน JavaScript นอก Browser ได้ โดยทำงานบน Server หรือ Terminal ของเครื่องเรา

ก่อนหน้านี้ JavaScript ทำงานได้แค่ใน Browser เท่านั้น แต่ Node.js เปลี่ยนเกมโดยใช้ V8 Engine ของ Google Chrome มาขับเคลื่อน

🌍 REAL-WORLD USE CASE

คุณเป็น Developer ที่รู้ JavaScript อยู่แล้ว — ด้วย Node.js คุณสามารถ สร้าง Backend API, เว็บเซิร์ฟเวอร์, Script อัตโนมัติ ได้ทันที โดยไม่ต้องเรียนภาษาใหม่

📌 Node.js ใช้ทำอะไรได้บ้าง?

  • 🌐 สร้าง REST API สำหรับ Web/Mobile App
  • 🤖 รัน Script อัตโนมัติ เช่น resize รูป, อ่านไฟล์ CSV
  • 🔄 ทำ Real-time App เช่น Chat, Live Notification
  • 🧪 สร้าง Build Tool เช่น Webpack, Vite, ESLint
  • 📦 จัดการ Package ผ่าน npm (Node Package Manager)

⚡ เปรียบเทียบ: Browser JS vs Node.js

คลิกที่แต่ละด้านเพื่อดูความแตกต่าง

🌐

Browser JS

  • มี window, document
  • จัดการ DOM ได้
  • ❌ อ่าน/เขียนไฟล์โดยตรงไม่ได้
  • ❌ เข้าถึง OS ไม่ได้
  • ทำงานใน Tab ของ Browser
🟢

Node.js

  • ❌ ไม่มี window, document
  • มี process, global
  • ✅ อ่าน/เขียนไฟล์ได้ (fs module)
  • ✅ เข้าถึง OS, Network ได้
  • ทำงานบน Terminal / Server

👆 คลิกเพื่อดูรายละเอียด

✅ Checkpoint 1 — ก่อนไปต่อ ตรวจสอบว่าคุณเข้าใจ:

  • Node.js คือ JavaScript Runtime ที่รันนอก Browser
  • Node.js ใช้ V8 Engine เดียวกับ Chrome
  • ความแตกต่างหลักของ Browser JS และ Node.js

🔧 CommonJS vs ES Modules

Node.js รองรับ 2 ระบบ Module หลัก — เลือกให้ถูกต้องตั้งแต่ต้น!

CommonJS — รูปแบบดั้งเดิมของ Node.js ใช้ require() และ module.exports

math.js (สร้าง module)
// ไฟล์: math.js — สร้าง module ของเราเอง
function add(a, b) { return a + b; }
function multiply(a, b) { return a * b; }

// export เพื่อให้ไฟล์อื่นใช้ได้
module.exports = { add, multiply };
app.js (ใช้ module)
// ไฟล์: app.js — นำ module มาใช้
const { add, multiply } = require('./math'); // ./ = ไฟล์ local

console.log(add(3, 5));      // → 8
console.log(multiply(4, 6)); // → 24

ES Modules — มาตรฐานใหม่ ใช้ import / export เหมือนใน Frontend

math.mjs
// ไฟล์: math.mjs
export function add(a, b) { return a + b; }
export function multiply(a, b) { return a * b; }
app.mjs
// ไฟล์: app.mjs
import { add, multiply } from './math.mjs';

console.log(add(3, 5));      // → 8
🌍 REAL-WORLD USE CASE

ในโปรเจกต์จริง เช่น Express.js API — เราแยกโค้ดเป็น Module เช่น routes/users.js, middleware/auth.js, utils/validate.js แล้ว require/import เข้ามาใน server.js

🎯 ทดสอบ: เลือกคำสั่งที่ถูกต้อง

โค้ดด้านล่างใช้ Built-in Module ชื่ออะไร? เลือกคำตอบ:

const os = require('os');
console.log(os.platform());   // → 'win32' / 'darwin' / 'linux'
console.log(os.cpus().length);  // → จำนวน CPU core
console.log(os.freemem());     // → RAM ที่ว่างอยู่ (bytes)

✅ Checkpoint 3 — ตรวจสอบความเข้าใจ:

  • Module 3 ประเภท: Built-in, Local, Third-party
  • CommonJS ใช้ require() / module.exports
  • ES Modules ใช้ import / export
  • Local module ต้องใส่ ./ นำหน้า path

📂 fs Module — อ่าน/เขียนไฟล์

สิ่งที่ Browser JS ทำไม่ได้ แต่ Node.js ทำได้ คือ อ่านและเขียนไฟล์ บนเครื่อง

const fs = require('fs');

// อ่านไฟล์แบบ Synchronous (รอจนเสร็จก่อน)
const content = fs.readFileSync('data.txt', 'utf8');
console.log(content); // แสดงเนื้อหาไฟล์
const fs = require('fs');

// เขียนไฟล์ใหม่ (ถ้าไฟล์มีอยู่แล้วจะ overwrite)
fs.writeFileSync('output.txt', 'สวัสดี Node.js!');
console.log('เขียนไฟล์สำเร็จ ✅');

// เพิ่มต่อท้ายไฟล์ที่มีอยู่
fs.appendFileSync('output.txt', '\nบรรทัดใหม่');
const fs = require('fs');

// อ่านไฟล์แบบ Async (ไม่บล็อก, ทำงานอื่นไปพร้อมกันได้)
fs.readFile('data.txt', 'utf8', (err, data) => {
  if (err) {
    console.error('อ่านไม่ได้:', err.message);
    return;
  }
  console.log('เนื้อหา:', data);
});

console.log('บรรทัดนี้รันก่อน! (non-blocking)');

🗺️ path Module — จัดการ Path

path ช่วยให้โค้ดทำงานได้ทั้ง Windows (\) และ Mac/Linux (/)

const path = require('path');

// รวม path (ทำงานได้ทุก OS)
const fullPath = path.join('/users', 'john', 'file.txt');
// → /users/john/file.txt

// ดึงชื่อไฟล์จาก path
path.basename('/users/john/file.txt'); // → 'file.txt'

// ดึง directory ของไฟล์
path.dirname('/users/john/file.txt');  // → '/users/john'

// ดึงนามสกุลไฟล์
path.extname('image.png');            // → '.png'

// __dirname = directory ของไฟล์ที่กำลังรัน (มีประโยชน์มาก!)
console.log(__dirname); // → /home/john/myproject
🌍 REAL-WORLD USE CASE

ใช้ path.join(__dirname, 'uploads', filename) เพื่อสร้าง path บันทึกไฟล์ที่ upload ขึ้นมา — ทำงานได้ถูกต้องทั้ง Windows และ Linux Server

✅ Checkpoint 4 — ตรวจสอบความเข้าใจ:

  • fs.readFileSync อ่านไฟล์แบบ Sync, fs.readFile อ่านแบบ Async
  • fs.writeFileSync เขียนทับ, fs.appendFileSync ต่อท้าย
  • path.join() รวม path ให้ทำงานได้ทุก OS
  • __dirname = directory ของไฟล์ปัจจุบัน

🌐 สร้าง HTTP Server ด้วย Node.js

Node.js มี http module ในตัว — ทำให้เราสร้างเว็บเซิร์ฟเวอร์ได้โดยไม่ต้องติดตั้งอะไรเพิ่ม!

Hello World Server

const http = require('http');

// สร้าง server — รับ request แล้วตอบกลับ
const server = http.createServer((req, res) => {
  // req = request (ข้อมูลจาก client)
  // res = response (ข้อมูลที่จะส่งกลับ)

  res.writeHead(200, { 'Content-Type': 'text/plain; charset=utf-8' });
  res.end('สวัสดี! นี่คือ Node.js Server ของฉัน 🟢');
});

// เปิด server ที่ port 3000
server.listen(3000, () => {
  console.log('Server รันอยู่ที่ http://localhost:3000');
});
Terminal
$ node server.js
Server รันอยู่ที่ http://localhost:3000
เปิด browser แล้วไปที่ http://localhost:3000

🛣️ Simple Routing

ในโปรเจกต์จริง เราต้อง ตรวจสอบ URL เพื่อส่งคำตอบต่างกัน

const http = require('http');

const server = http.createServer((req, res) => {
  res.setHeader('Content-Type', 'application/json');

  // ตรวจสอบ URL path
  if (req.url === '/') {
    res.writeHead(200);
    res.end(JSON.stringify({ message: 'หน้าแรก' }));

  } else if (req.url === '/about') {
    res.writeHead(200);
    res.end(JSON.stringify({ message: 'เกี่ยวกับเรา' }));

  } else {
    res.writeHead(404); // Not Found
    res.end(JSON.stringify({ error: 'ไม่พบหน้าที่ต้องการ' }));
  }
});

server.listen(3000);
🌍 REAL-WORLD USE CASE

ในโปรเจกต์จริง เราใช้ Express.js ซึ่งเป็น framework ที่ทำให้การเขียน routing ง่ายและสะอาดกว่านี้มาก — แต่เบื้องหลัง Express ก็ใช้ http module นี้อยู่ดี!

✏️ เติมโค้ดให้ครบ

เติมคำสั่งที่ขาดไปเพื่อสร้าง HTTP Server ที่ตอบกลับ status 200:

const http = require('http');
const server = http.((req, res) => {
res.(200);
res.('Hello!');
});
server.listen(3000);

✅ Checkpoint 5 — ตรวจสอบความเข้าใจ:

  • http.createServer(callback) สร้าง server
  • req = ข้อมูลจาก client, res = ข้อมูลที่ส่งกลับ
  • res.writeHead(statusCode) กำหนด HTTP status
  • server.listen(port) เปิด server ที่ port นั้น
  • Routing = ดู req.url แล้วตอบกลับต่างกัน
